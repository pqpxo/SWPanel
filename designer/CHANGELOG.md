# Changelog

## 1.2.0

- Icon, text and value sizes can be any whole number, as well as the usual ones.
- Elements can be moved forward, backward, to the front and to the back.
- Elements can run past the screen edge, or be bigger than the screen.

## 1.1.0

The preview now shows live states from Home Assistant: tiles light up, and sensors, status
tiles and brightness sliders show their real values.

## 1.0.0

First release as a Home Assistant app.
